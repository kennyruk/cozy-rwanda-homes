# Smart Rent product build

## Goal
Build Smart Rent as a polished Rwandan rental marketplace using the supplied navy-and-teal identity, the existing logo artwork as the visual reference, and the provided product specification.

## Experience
- Replace the blank screen with a property-first homepage featuring a Rwanda-inspired photographic banner, prominent search, featured listings, location discovery, the three-step rental journey, and the free landlord callout.
- Add working marketplace views for property search and property details, plus purposeful tenant, landlord, chat, saved-home, and property-listing experiences.
- Make navigation, search, filters, favorites, galleries, forms, dialogs, and mobile navigation interactive with realistic sample listings.
- Treat verified status accurately in the sample data rather than applying it to every listing.

## Visual system
- Build a restrained warm-white, deep-navy, charcoal, teal, and neutral token system based on the supplied brand board.
- Recreate a clean, usable Smart Rent logo family from the supplied logo artwork for the navigation and app icon treatment.
- Use strong professional typography, compact radii, editorial spacing, restrained shadows, and subtle motion.
- Use cohesive, high-quality Rwanda-inspired property imagery rather than generic placeholders.
- Avoid purple gradients, glass-heavy styling, oversized pills, generic dashboard patterns, and Airbnb/Zillow imitation.

## Technical details
- Keep the app in the existing TanStack structure with reusable marketplace components and route-specific metadata.
- Implement responsive layouts intentionally for phones, tablets, and desktop with no horizontal overflow.
- Use local sample content for the first complete visual build; persistent accounts, listings, chat, and rental requests will use Lovable Cloud when those live workflows are connected.
- Verify the key discovery flow and final layouts in the running preview across desktop and mobile sizes.
